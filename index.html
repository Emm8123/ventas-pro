📖Manual de uso

Empezar

1. En Configuración poné el nombre, teléfono y moneda del negocio.
2. Cargá Productos y Servicios.
3. Agregá Clientes.
4. Tocá Punto de venta.

Vender

Elegí productos, tocá Pagar, elegí la forma de pago (Efectivo, Tarjeta, Transferencia o Fiado). Se guarda la venta y podés imprimir el ticket, la factura o el comprobante.

Fiado

El fiado suma deuda al cliente y NO entra a caja. Cuando pague, desde Fiados o el cliente tocá Cobrar fiado: baja la deuda y entra a caja.

Compras

Registrá mercadería: sube el stock y descuenta de caja.

Órdenes y Presupuestos

Órdenes = trabajos con seguimiento (pendiente/proceso/listo/entregado). Presupuesto = cotización para el cliente.

Datos

Todo se guarda en este dispositivo (no usa internet ni base de datos). Usá Copia de seguridad seguido para tener una copia.
